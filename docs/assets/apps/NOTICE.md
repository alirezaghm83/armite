# Application artwork

These assets identify third-party applications in Armite. Application names, logos,
and trademarks belong to their respective owners. They do not indicate endorsement
or affiliation. Armite’s code license does not grant trademark rights.

`./sources.json` records the exact upstream URL, collection, and SHA-256 for every
imported icon. Icons are served locally, never requested from another service while
using the app picker.

## Collections

- **Dashboard Icons**: https://github.com/homarr-labs/dashboard-icons, pinned at
  `83f32e08257b66fbd971ac8d7645f5b38d52e85d`. The accompanying project license is
  `DASHBOARD-ICONS-LICENSE.txt`; individual marks remain their owners’ trademarks.
- **Papirus icon theme**: https://github.com/PapirusDevelopmentTeam/papirus-icon-theme,
  pinned at `bf539287ef5dc18529424a02cccee76175920a6f`. SVG artwork is distributed
  under GPL-3.0; see `PAPIRUS-LICENSE.txt`. These standalone image files are unchanged
  and their preferred editable SVG source form is included.
- **Devicon**: the C++ icon from https://github.com/devicons/devicon. See
  `DEVICON-LICENSE.txt` and the exact asset URL in `sources.json`.
- **Publisher / project artwork**: website favicons or repository artwork for
  foobar2000, SumatraPDF, WinRAR, Wireshark, WinSCP, PowerToys, Everything,
  Notepad++, WinMerge, uv, NanaZip, and Hiddify. Exact publisher URLs are in
  `sources.json`. Original branding is retained, for application identification.

The authored UI glyphs in `../../ui-icons.js` are part of Armite’s MIT-licensed code.
