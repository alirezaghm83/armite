A small tool for a new generation of PCs.

Inspired by the simplicity of Ninite, built independently for Windows ARM64. Armite is a download-link picker, not a combined installer. It doesn’t host or modify application binaries.

Know where your downloads come from.

Architecture and installer URLs are sourced from Microsoft’s WinGet manifests and publisher release pages. ARM64EC and universal packages are labeled. Each app includes its source record and publisher page. Links are a dated snapshot; verify publisher signatures before running files.
