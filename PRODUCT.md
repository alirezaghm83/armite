# Armite

Platform: web. Static, buildless GitHub Pages application in `docs/`.

Purpose: collect direct Windows ARM64 application downloads from a curated, source-attributed catalog. Users recognize apps, choose artifacts, select several apps, then copy URLs, export an aria2 list, or share their selection.

Audience: Windows on ARM owners, including technical users setting up Snapdragon PCs.

Product truth: 68 catalog records, 56 currently selectable, checked-in source evidence and dates. Architecture is source-declared; file-header checks do not prove CPU architecture or digital signatures. Armite collects links and never installs software itself.

Required flows: search, categories, unavailable-app toggle, checkboxes, variant selection, selection removal/clear, starter packs, clipboard fallback, plain/aria2 export, share hash restoration, local persistence. Preserve all existing download data and meaningful app icons.

Current user direction: substantial replacement visual identity; premium, minimalist, exceptional typography and hierarchy, no repetitive card dashboard. Desktop and mobile must work. Only 7% usage allowance remains: one coherent implementation, bounded verification, local commits only; do not push.

These facts come from the explicit request and current implementation; no additional product claims are assumed.
